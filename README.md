# PLAYWRIGHT AUTOMATION

## Manejo de mensajes de commits
|   Tipo de cambio |   Mensaje                                              |
|------------------|--------------------------------------------------------|
|   feat           |    para nuevas características                         |
|   fix            |    para corrección de errores                          |
|   docs           |    para cambios en la documentación                    |
|   refactor       |    para refactorización de código sin cambios lógicos  |

<br/>

> EJEMPLO: 
> ```javascript
> git commit -m "feat - nuevos casos de prueba módulo compras"
> ```

## Stack
* Playwright
* Newman
